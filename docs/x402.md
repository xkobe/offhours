# x402 Pay-Per-Call Middleware — HoodScope MCP

PRD 阶段五交付。为 6 个 MCP 付费工具实现 x402 支付协议（按次付费，免 API Key）。

## 协议形态

- **网络**：`eip155:4663`（Robinhood Chain）
- **结算资产**：USDG `0x5fc5360d0400a0fd4f2af552add042d716f1d168`（6 decimals，≈$1）
- **方案**：`exact` — EIP-3009 `TransferWithAuthorization`
- **支付方**：离线签名（gasless），由 facilitator 代广播结算
- **EIP-712 domain**：`name="Global Dollar"`、`version="1"`（合约无 version()，沿用 USDC 惯例）、`chainId=4663`、`verifyingContract=USDG`——name/symbol/decimals 已在链上核验

## 运行模式

**dev（默认）**：确定性 dev signer（`0xab…ab` 私钥）真实签名 EIP-3009，但**不上链结算**。
每个工具输出首行为 X402 收据：`X402 paid $0.05 (USDG @ eip155:4663) · payer … · → … · nonce 0x… · mode dev · settlement dev_only`。

**live**：设置以下环境变量后自动切换，执行完整 challenge → sign → facilitator verify/settle 循环：

```
X402_PAYEE=0x…            # 服务收款地址（必需）
X402_SIGNER_PRIVATE_KEY=0x…  # 服务端签名私钥（必需；仅用于生成 requirements/收据，MCP 不持用户私钥）
X402_FACILITATOR_URL=…    # facilitator（如 x402.org/facilitator）
RPC_URL=…                 # 默认 rpc.mainnet.chain.robinhood.com
```

合规边界（SEC 2026-04 DeFi 前端豁免指引）：固定价格、纯自托管、MCP 不触碰用户钱包与私钥。

## 关键实现细节

- USDG 非 SDK 默认资产表 → `setSpendControls(false)`；生产可换 `allowedAssets` 上限
- 签名需链上读 EIP-712 domain → `toClientEvmSigner(account, publicClient)` 组合签名器
- nonce 为 32 字节随机 hex（协议要求）；validBefore = now + maxTimeoutSeconds(300)
- 未配置 X402_PAYEE 时 dev signer 同时作为 payTo，便于本地闭环验证
